# Programming Advices Courses

My solutions, notes and practice projects from the [Programming Advices](https://programmingadvices.com) learning path. It runs from computer foundations and C++ through OOP, data structures, SQL Server, T-SQL and ADO.NET in C#.

## Contents

| Folder | Topics |
|---|---|
| `Course 1 - Foundations Level 1` | Binary and hex systems, bytes, variables and constants, programming languages, networking basics |
| `Course 3 - CPP Level 1` | C++ basics: output, input, operators, math functions, structures, loops and arrays |
| `(2,4,5,7,8 ) courses - Algorithms & (+250 problem solving )` | Algorithms Level 1 and 250+ solved problems in C++, including a full date library |
| `Course 6 - Introduction to Programming Using Cpp Level 2` | Recursion, 2D arrays, vectors, structures, pointers and references |
| `Course 10 - OOP as it Should Be_Concepts` | OOP in C++: classes and objects, properties, constructors, destructors, calculator project |
| `Course 12 - Data Structures Level 1` | STL stack and queue, singly and doubly linked lists |
| `013 -DataStructuer Projects` | Stack and queue built on a doubly linked list and on a dynamic array, undo / redo |
| `Small Projects Using C++` | Console projects, including an ATM system |
| `014_Small Projectusing C Sharp #` | First C# console projects |
| `016_OOP As It Should Be In CSharp` | OOP in C#: static vs private constructors, inheritance, abstract classes, composition, interfaces |
| `015_Database Level 1_SQL_Concepts and Practice` | SQL basics: SELECT, DISTINCT, WHERE, IN, BETWEEN, ORDER BY, TOP, aggregates and more |
| `017_Problems Query SQL SERVER` | SQL Server query problems, with database backups to restore |
| `Course 21 - T-SQL` | Variables, IF and CASE, loops, built-in functions, CTEs, stored procedures, triggers, error handling |
| `ADO.NET` | Data access with ADO.NET: retrieve, insert, update and delete, parameterized queries, a 3-tier contacts app |
| `Zero Web Problems` | String and list problems |

## Run

- **C++**: open the `.sln` in Visual Studio (Desktop development with C++).
- **C#**: open the `.sln` in Visual Studio.
- **SQL**: restore the `.bak` files or run the `.sql` scripts in SQL Server Management Studio. The ADO.NET samples connect to a local `ContactsDB` with Windows authentication.
